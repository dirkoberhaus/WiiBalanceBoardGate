WiiBalanceBoardGate

ESP32 firmware that bridges a Wii Balance Board (classic Bluetooth) to any phone or laptop over its own WiFi access point - live weight/ center-of-pressure data as JSON over WebSocket, plus a small built-in web UI with an archery-specific 60%/40% balance preset.

Get started

🔧 Flash or update a board Browser-based USB flasher - no install, works for first setup and every later update 📋 Benutzeranleitung German end-user quickstart - connecting, syncing, using the board
